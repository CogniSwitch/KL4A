# SOPKB examples

These examples are complete, reviewable SOP Knowledge Bundles. Each one includes
the source, normalized sections, evidence, knowledge items, relations, rules, and
task contexts produced by the SOPKB workflow.

- [Customer Refund Policy](customer-refund-policy.md)
- [Customer Support & Returns Policy](customer-support-policy.md)
- [Category Returns Policy](category-returns-policy.md)

The bundle files remain in the repository so they can be cloned, inspected, and
queried with `sopkb-cli`.
