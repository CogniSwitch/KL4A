# Category Returns Policy

This example demonstrates how a policy with category-specific exceptions becomes
a bundle of evidence-backed knowledge, relations, rules, and agent task contexts.

[Browse the complete bundle in the repository](https://github.com/CogniSwitch/KL4A/tree/main/examples/category-returns-policy).

To query a local checkout:

```bash
sopkb-cli knowledge search examples/category-returns-policy/bundle "Major Appliances restocking"
```
